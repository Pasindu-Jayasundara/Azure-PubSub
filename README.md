# Azure Web PubSub Chat

A simple real-time chat application built with React, Vite, Express, and Azure Web PubSub.

## About

This project is a browser-based chat demo that lets multiple users exchange messages in real time. The React frontend provides the chat interface, while the Express backend securely negotiates Azure Web PubSub connections so users can join the same chat group without exposing the Azure connection string in the browser.

The React client connects to Azure Web PubSub through a short-lived client access URL generated by the Express server. Messages are sent to the `sample_chat` group and broadcast to connected users.

## Prerequisites

- Node.js 18 or later
- An Azure Web PubSub resource
- The Web PubSub connection string

## Configuration

Create `server/.env`:

```env
PORT=8080
HUB_NAME=sample_chat
WEB_PUBSUB_CONNECTION_STRING=<your-azure-web-pubsub-connection-string>
```

Create `client/.env`:

```env
VITE_SERVER_URL=http://localhost:8080
```

Do not commit either `.env` file or any Azure connection string.

## Installation

Install dependencies in both applications:

```bash
cd server
npm install

cd ../client
npm install
```

## Running Locally

Start the server in one terminal:

```bash
cd server
npm run dev
```

Start the client in another terminal:

```bash
cd client
npm run dev
```

Open the URL shown by Vite, normally:

```text
http://localhost:5173
```

Open the app in multiple browser windows or tabs to test real-time messaging.

## API Endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/health` | Returns the server health status and hub name |
| `GET` | `/negotiate?user=<name>` | Returns an Azure Web PubSub client access URL |

- `npm start` starts the server with Nodemon.

## Production Notes

- Store the Azure connection string in a secret manager or deployment environment.
- Restrict CORS to the deployed client origin instead of allowing every origin.
- Configure the client `VITE_SERVER_URL` with the deployed server URL.
- Use HTTPS for the client and server in deployed environments.
